## 技术说明
- `labs/engine.js`：操作面板、画面实时更新、项目数据导出、模块切换。
- `labs/catalog.js`：从 `explore/data.js` 的原始主题清单读取第28—108项标题与领域描述。
- `explore/app.js`：108目录卡片与模块路由，第03—108项转到 `labs/?id=N`。
- 静态前端。默认不将用户填写的个人答案上传服务器；使用者可主动导出JSON，部分画布可导出PNG/SVG。切换页面不会自动形成个人能力画像。

## 科学与产品边界
108个原始主题是跨领域活动机会，不是已证实的108种独立先天天赋。当前没有科学验证的常模、信效度、长期复测或现实预测能力。不能根据单次点击、答题或短作品做天赋鉴定、医学心理诊断、职业预测、道德高低评价。

## 后续提高质量的优先事项
1. 邀请成年人自愿试用，重点检查任务是否明确、音频是否清晰、是否产生有意义的作品。
2. 为不同活动增加真正不同的新材料与重复测验，记录每次材料版本，避免记住固定答案。
3. 为高层级领域引入合法可验证的素材与任务外现实表现，而非模拟点击替代。
4. 增强按本人自愿选择的本机作品导入/继续编辑能力、无障碍适配。
5. 对需要评估效度的项目另设计合规研究流程，不默认收集个人表现。
