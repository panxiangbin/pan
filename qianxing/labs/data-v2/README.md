## 用户体验
- 九份不同的、可复核的原创合成数据：1轮练习、3轮首次调查、3轮新数据挑战、2轮跨行业迁移。
- 每轮有14日、两个细分组的28行基础数据，通过程序实际计算分子、分母、比例和独立来源数量；没有连接用户真实店铺或其他个人数据。
- 点击图表点或表格日期，切换全部/两个业务组、总量/事件数/事件率/核实来源；可以主动导出当前筛选数据的CSV。
- 调查阶段最多选择3条证据且必须至少2条才能进入结论阶段。类型包括分组核查、分母核查、独立系统对账、流程/日志以及未经证实的群聊猜测。
- 选择一种可能解释、一个建议行动与自己的确定程度；可自行写备注；允许选“根因暂不确定”或暂时跳过，不强制猜测。
- 完成后展示多维过程记录，并可下载JSON。所有选择/可选备注保存在当前浏览器localStorage，不上传服务器，关闭或清理浏览器可能导致遗失，建议主动导出。
- 外层网站保持简洁。没有人格、先天天赋、智力或职业预测等级，也不自动对一段自由文本做AI“好坏”评价。

## 九个案例
1. **操作练习** 仓库订单数翻倍，实际是重复导入。对比原始行数与唯一订单。
2. **首次** 承运商分组延误：乙线路晚到率升高而甲线路基本正常。
3. **首次** 小样本成交率：5人4成交，需看分母；加入基于独立样本假设的示意性Wilson区间。
4. **首次** 整体签约率下降：各分组比率相近、渠道结构发生变化。
5. **新数据** 温度探头的华氏/摄氏单位与阈值不一致，需要核对独立探头。
6. **新数据** 周末访问量周期性下降：没有足够证据确认新故障，允许正确选择“无异常”。
7. **新数据** 日报同步晚到导致入库数下降，业务系统实际任务量正常。
8. **迁移** 一批次退货率集中异常，不应一律认定所有产品不合格。
9. **迁移** 设备告警阈值改变，模拟误报警，需要独立参考记录校验。

## 分析数学边界
- 比例统一采用 **SUM(分子) ÷ SUM(分母)**；绝不能把各渠道/各日百分比简单算术平均作为总体比例。
- 对“5人4次成交”的不确定性，使用标准的二项分布Wilson区间演示；这依赖独立同分布样本等条件，不能据此证明任何现实渠道真正稳定改善。
- 因果根因来自模拟题本的预设事件记录，并非仅凭图表本身就可证实因果。真实事故仍需现场和独立证据复核。
- 「无异常」是根据本模拟案例的基线和设定判定的结论，不代表任何周末流量下降都正常。
- 不对专业难度、不同题本等价性、真实操作误差、受试者常模或心理测量信效度做未经验证的声明。
- 图表及分组指标仅为虚构教学演示；导出的数据若用于业务决策应另行核验真实来源。

## 后续改进方向
目前只有一种题本，源码公开后玩家可能记住答案；后续应制作不同但等价的平行题本、引入更复杂多字段数据及自主选择核查成本，让用户在不同日期复测。同时开展真实用户试玩和题目质量改进，再考虑专业测评研究。不要将结果变成一个未经验证的先天天赋百分比。
