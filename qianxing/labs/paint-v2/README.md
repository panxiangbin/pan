## 为什么这样改
旧版第06项是单页画布与调色演示，无法看到完整创作与修改过程。
V2重点是：独立绘画 → 观察光照改变后直接修订原画 → 自愿学习 → 换新静物迁移 → 再次编辑原画 → 保存四张独立作品。
该流程比机械地追加选择题更贴近创作中的观察、决策和修改。但它依然只是探索式原型，不是艺术测验。

## 实际功能
- 完全在浏览器操作的真实数字画布，内部尺寸960×600，支持鼠标、触摸屏、手写笔PointerEvent。
- 四种工具：自由画笔、铅笔、马克笔、橡皮；颜色预设与浏览器自定义取色；粗细、透明度；撤回、重做、清空、辅助九分构图网格（网格是UI辅助线，不导出）。
- 每笔存储：工具、颜色、宽度、透明度、坐标点序列；撤回不会破坏其他笔画。
- 练笔不计入四张正式作品；作品一为冷光苹果与陶瓷瓶，作品二同一静物转暖光后在旧笔画基础上直接修改。
- 自愿分三级学习构图/明暗/配色/改稿方法；作品三换成梨与蓝色杯子全新绘制，作品四在同一新对象暖光条件下直接修改。
- “修订”从前一版复制原始笔画对象，之后新增的笔画独立记录；首次作品数据不会因后续编辑而被覆盖。
- 当画布上实际产生笔画或修订时才解锁正常完成按钮；不便操作的用户也可明确选择跳过，不评价好坏。
- 每一步可写一段可选创作记录。
- 四张独立作品以四个分别点击下载按钮导出为PNG，严禁合并拼贴、九宫格、左右双图或多格分镜；参考静物不会贴入用户画布的PNG。
- 所有笔画、工具设置、阶段信息作为JSON导出并可重新导入编辑，满足可编辑性与长期继续修改。
- 本机localStorage自动保存草稿，以便意外刷新后恢复；默认不上传内容、无需账户。请主动下载JSON备份，不保证不同浏览器或清理缓存后的数据留存。
- 结果仅显示笔画/颜色类别/修改记录/自选学习条数；没有艺术“天赋分”、排行榜、人格或职业判定。

## 代码组成
- index.html、style.css：极简、明亮的手机/电脑界面。
- paint-core.mjs：纯数据与笔画约束、五阶段作品、撤回重做、修改差异、JSON验证与描述性统计。
- painter.mjs：数字画布绘制、浏览器pointer事件、单幅PNG。
- app.mjs：导航、独立参考图、工作台、分阶段任务、自愿微学习、作品下载、导出导入和恢复。
- assets/：四幅独立图片、一份favicon。
- 无收费SDK、无需CDN，不依赖麦克风摄像头，不记录用户身份。

## 产品能力边界
- 现有统计不评价绘画质量或审美创新性。笔画越多、颜色越多，不表示艺术水平越高。
- 没有专业评审、常模、信效度及跨题本等价性研究；用户的设备、既有训练、视觉条件与手部操作都可能影响作品。
- 如果用户跳过阶段，报告应明确没有足够作品观察，而不是给低天赋结论。
- 同一静物从冷调到暖调，虽然能帮助尝试新条件，但其难度并没有经过专业等价性测量。
- 后续可增加真正不同的素材、自愿多日复测、原创作品人工讨论、自由创意任务。不能承诺一组数字画布活动就测出天赋。
