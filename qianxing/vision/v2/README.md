# 潜星计划 V2｜第02项「潮汐码头·异常货运调查」

## 当前版本
- 版本：2026-10-29，交互式可运行样板
- 正式入口：/qianxing/vision/（重定向到 /qianxing/vision/v2/）
- 旧版保留：/qianxing/vision/v1.html
- 目的：在不同场景中观察视觉变化察觉、误报与漏报、对结构化扫描提示的使用、初探与新素材表现。
- 不是心理、医学或职业测验；没有人群常模/信度/效度验证，不作先天天赋判定。

## 已有内容
- 1轮练习（明显变化，不计分）
- 3轮初探：位移、封条细节、无变化
- 可选的3级结构化观察方法提示
- 3轮全新素材：高度变化、细节变化、无变化
- 1轮迁移：仓库货物缺失
- 1轮动态监控：实际Blender逐帧渲染的叉车移动与货物封条变化视频
- 完整任务记录：每次选择、正确位置、是否误报/漏报/不确定、观察/作答用时、重看次数、提示级别、视频播放次数
- 自愿JSON导出；默认无登录、不上传答案，刷新清空本次记录
- 2026-10-29本机浏览器脚本测试包括完整9轮、手机390px、视频可读、素材校验、JSON导出。

## 素材
静态 A/B：16 张 960x560 单镜头 Blender 渲染 JPG；
动态素材：固定机位逐帧渲染后压制MP4，视频共16帧约2.7秒；
题本：assets/manifest.json（每轮角色、目标、位置以及素材配对信息）。
「无变化」题强制使用完全相同字节的A/B图片，防止渲染噪声导致误报。
使用者能查看源码和manifest找到答案，因此目前仅是静态站点研究原型，不是防作弊正式测评。

## 质量边界
- 场景为可追踪的3D工业场景原型，不是予华的真机或真实监控画面。
- 现阶段主要追求变化可核查和无障碍操作，尚未通过题目等价性、代表性取样、年龄组常模及独立心理测量验证。
- 依赖静态题本，反复挑战可能记住答案；后续要制作更多平行题本和延迟复测。
- 视觉条件、浏览器、亮度、色觉差异、反应时间测量误差可能影响表现。
- 不能将前后3/3的差别当成能力变化的科学证据。
- 后续应以成年人自主试玩、数据隐私说明、不同设备误差和材料质量验收为前提，再考虑更高规格音视频和研究模式。
